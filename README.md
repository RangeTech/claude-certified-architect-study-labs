# CCA-F Study Guide

A complete, self-contained preparation kit for the **Claude Certified Architect – Foundations (CCA-F)** exam, covering all five domains. Passing score: 720. 60 questions, 120 minutes.

Domain weights (exam guide): D1 Agentic Architecture & Orchestration 27%, D3 Claude Code Configuration & Workflows 20%, D4 Prompt Engineering & Structured Output 20%, D2 Tool Design & MCP Integration 18%, D5 Context Management & Reliability 15%.

## Start here
1. Open `CCAF-Study-Checklist.xlsx`. The Checklist tab is ordered P0 (orientation) through the five domains to final prep; work top to bottom.
2. Update only the Status dropdown, Date done, and Notes columns. The Dashboard tab computes progress per phase and per domain automatically.
3. Resource links in the checklist open the docs pages, Academy courses, the interactive drill, and the labs directly.

## Folder map
- `CCAF-Study-Checklist.xlsx` .......... master checklist + progress dashboard
- `01-Official-Resources/` ............. index of official Anthropic links (exam guide, docs, Academy) for all five domains
- `02-Interactive-Drills/` ............. 25-scenario honeypot drill (open the HTML in a browser; filter by domain)
- `03-Hands-On-Labs/` .................. 15 hands-on labs, one folder per domain (`D1/` … `D5/`)
- `03-Hands-On-Labs/_AnswerKeys/` ...... worked solutions and reference outputs per lab; attempt the lab first
- `04-Community-Resources/` ............ unofficial prep sites and guides, with cautions
- `05-Exam-Day/` ....................... one-pager strategy + terminology hit list for the final 24h

## Suggested path
Orient (exam guide + sample questions) → for each domain: baseline drill → docs → labs → re-drill → final prep (full 25-question drill cold, official practice exam, exam-day one-pager). The checklist encodes this sequence with time estimates.

## Ground rules
- When any unofficial material (including the 12-week repo) disagrees with the live docs, the docs win. The exam is written against the docs.
- Do the labs. The exam is scenario-based at a 301 level; it punishes doc-reading without hands-on scar tissue.
- Answer keys are for after an attempt (or when stuck), not instead of one. The discrimination the exam tests is built by observing the behavior yourself.
